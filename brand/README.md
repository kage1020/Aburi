# Brand

Every asset under `docs/public/brand/` is generated by `brand/generate.mjs`. Run
`node brand/generate.mjs` after changing anything here; the output is byte-for-byte
reproducible, so a clean tree after a run means the committed assets are current.

## Where the mark comes from

The mark is Aburi's own fingerprint. A fingerprint is `sha256(utf8).hex.slice(0, 12)`
(see `packages/core/src/fingerprint/hash.ts`), and a 4×4 grid holds exactly 16 bits —
the first four hex digits.

```
input       "@aburi/core"
fingerprint 5e7244d9eda9
pattern     5e72
```

Each hex digit is one row, most significant bit on the left:

```
5 → 0101      · ■ · ■
e → 1110      ■ ■ ■ ·
7 → 0111      · ■ ■ ■
2 → 0010      · · ■ ·
```

A set bit is a filled square — a Symbol the scan surfaced. A clear bit is a small dot —
still latent. That is the whole idea of the tool in one figure, and anyone can recompute
it. `generate.mjs` asserts the derivation on every run and refuses to write if the hash
ever stops producing `5e72`.

Only the *input* was chosen. Seventeen meaningful candidates were scored mechanically on
using all four rows and columns, clustering into one mass, and lighting 6–10 cells;
`"@aburi/core"` won. No bits were nudged to improve the shape.

## Geometry

| | |
|---|---|
| viewBox | `0 0 64 64` |
| grid | 4×4, pitch 13, origin 7 |
| set bit | 11×11 square at the cell origin |
| clear bit | 5×5 dot, centred in the cell |
| ≤ 24 px | pitch 16, origin 0, 12×12 cells, dots dropped |

The small grid bleeds to the edges so that at 16 px each cell lands on exactly 3 device
pixels with a 1 pixel gap. Clear space around the mark is one cell.

## Palette

| | | |
|---|---|---|
| sear | `#B87514` | surfaced |
| latent (light ground) | `#F2E5D2` | not yet surfaced |
| latent (dark ground) | `#523409` | " |
| ink | `#14110E` | |
| paper | `#F2EFE9` | |

Measured: sear against white 3.75:1, against latent 3.02:1 on both grounds, against ink
5.01:1. Under protanopia, deuteranopia and tritanopia the sear/latent pair holds 3.38,
2.87 and 3.29. The size difference between squares and dots carries the same information
without colour, so the mark survives a single ink.

## Variants

| File | Use |
|---|---|
| `mark.svg` / `mark-dark.svg` | default, light and dark grounds |
| `mark-mono.svg` / `mark-mono-dark.svg` | alongside other brands, where the sear would clash |
| `mark-1bit.svg` | one ink — engraving, embroidery, stamps. Inherits `currentColor` |
| `mark-tile.svg` | grounds that cannot be controlled; the mark sits on its own ink square |
| `mark-small.svg` | 24 px and below |
| `mark-animated.svg` | cells grow from dot to square in reading order, 5 s cycle. Honours `prefers-reduced-motion` |
| `favicon-{16,32,48}.png`, `apple-touch-icon.png` | icons |
| `og.png` | 1200×630 social preview |

The cell pattern never changes between variants.
