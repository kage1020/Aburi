LSP enrichment now reads typescript-language-server's answers in the shapes that server sends. A `@throws` tag rendered as `*@throws* — {NotFoundError} …` or `*@throws* — RangeError` fills the caller's `Signature.inferredThrows`. So does a tag whose wrapped description the server starts on the line after the tag, and a `{@link X}`, `{@linkcode X}` or `{@linkplain X}` that tsserver renders as a tag of its own. The text is read by the rule `signature.throws` follows, so a tag whose text is a description still names nothing. One shape differs: braces the source writes on the line below the tag are a description to `signature.throws`, but the hover renders them like braces right after the tag, so their type is read.

`this.` calls inside a generic class (`(method) Store<T>.count()`) resolve to their member, and so do calls inside a static method, which reach the static `Class::m`. A method's call looks up a member of its own kind only, since TypeScript never lets `this.m` reach the other kind. A call the class Symbol holds, from a `static {}` block or a field initializer, resolves only when the class declares one kind of that name.

Decorated methods, decorated exported classes and anonymous default exports get their `startColumn` / `endColumn`, and so does a method whose decorator closes on its own line (`}) list() {`). A decorated declaration starts after its decorators, at its first modifier or else at its name, so a decorator on the declaration's own line no longer gives the `@`'s column. A class whose IR line is its first decorator's own keeps that decorator's column.

`inferredThrows` and the columns are not fingerprint inputs, but call edges are. A call that now resolves stayed unresolved before. A call from a static method resolved to an instance member of the name, and now reaches the static, or nothing when the static has no Symbol. A call from a static block or field initializer, in a class declaring both kinds of the name, resolved to the instance member and now has no edge. With an effect plugin loaded, the caller takes that callee's effects, takes another's or loses them, and so does every Symbol in its transitive callers' closure, so each one's `logic` fingerprint moves unless it already carries an effect on that target. An IR scanned before this release, compared with one scanned after, can therefore report any of them as changed. Rescan the base rather than comparing against a stored IR. `aburi diff <base>..<head>` scans both sides with the installed version and is unaffected.
