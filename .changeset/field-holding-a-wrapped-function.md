A class field holding a call handed a function is now a member. `handle = withAuth(async (data) => { … })` was a field, so its function was walked on the class: constructing the class reported what calling the member does, and propagated it to every `new UserService()` caller. A class of nothing but such fields was also hinted as a `pure DTO` and dropped, with the function's calls. The field is now a `method` Symbol (`UserService.handle`, or `UserService::handle` for a static field) with a null `signature` and `derivedBy` carrying `call-argument-function`. Its bodies are the functions handed directly to a call on the value's chain, read as a module-level `const` reads them. The wrapping call stays on the class, where it runs: on construction, or when the class is defined for a static field. A class of such fields is no longer dropped. A function deeper in the value (`withAuth(withLogging(() => …))`) or handed to `new` stays on the class.

The reading asks nothing about the call, as the `const`'s does not, so a field whose call is not a wrapper becomes a member too, and its callback is reported on the member rather than on construction or definition. That covers a call that runs its argument at once (`ids = xs.map((x) => …)` becomes `C.ids`, `static schema = z.string().refine((v) => …)` becomes `C::schema`) and one that registers it to run later (`timer = setInterval(() => { … }, 1000)`, `sub = store.subscribe(() => { … })`, `ready = p.then(() => { … })`). The callback's effects then no longer reach the callers of `new C()`.

An IR scanned before this release, compared with one scanned after, reports each such field's member as added, or among the dropped additions when its function is empty, tripping `--fail-on added`. A class that was dropped as a `pure DTO` is reported `dropped-toggled` to kept, tripping `--fail-on dropped-toggled` or `dropped-toggled:to-kept`. A class that was kept, and every caller its effects reached through `new`, moves its `logic` fingerprint where the function held a rule or an effect, tripping `--fail-on logic-changed` or `changed`. Rescan the base rather than comparing against a stored IR. `aburi diff <base>..<head>` scans both sides with the installed plugin and is unaffected.
