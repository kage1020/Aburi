"@aburi/framework-next": minor

A route handler is what a route file exports under an HTTP verb name

`framework:next:route` went to every `function` Symbol in `app/**/route.{ts,js}` whose name is an HTTP verb, exported or not, and to nothing else. Auth.js's `export const { GET, POST } = handlers` and a wrapped handler such as `export const GET = auth(async (req) => …)` are `const` Symbols and were not routes, while a local `function OPTIONS()` helper, which Next.js never dispatches to, was one. The plugin now reads what the module exports: a `function` or `const` Symbol is a route for each HTTP verb it is exported as, by the `export` keyword or by an export clause, so `async function POST() {}` with `export { POST }` stays a route and `const handler = NextAuth(options)` with `export { handler as GET, handler as POST }` is one, `handler` carrying `framework:next:route:GET` and `framework:next:route:POST`. A declaration the module does not export is not a route, nor one exported only as `default` or from inside a namespace. Both kinds get the one extKind `framework:next:route`, whose `baseKind` stays `function`. A page, layout or other App Router component whose default export is written `export { Page as default }` is now classified, as `export default Page` is. Export clauses are read by `@aburi/lang-typescript` from this release on; with an older one, a handler exported only through a clause is no longer a route.

The `api` fingerprint reads `extKind`, so it moves for every Symbol this classifies differently: the `const` and clause-exported handlers and clause-exported components that gain their kind, and the unexported verb-named functions that lose it. An IR scanned before this release, compared with one scanned after, reports those Symbols as api changes, and the Markdown projection's Boundary effect surface, which lists Symbols by a `framework:` extKind, gains or loses those of them that have effects. Rescan the base rather than comparing against a stored IR. `aburi diff <base>..<head>` scans both sides with the installed plugins and is unaffected.
