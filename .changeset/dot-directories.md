Files in a directory whose name starts with a dot, and dot files, are now scanned. Discovery kept every path with a dot-prefixed segment out, as a side effect of keeping `.git` out, so a GitHub Action written in TypeScript under `.github/actions/<name>/src`, Storybook's configuration in `.storybook` or a VitePress theme in `docs/.vitepress` got no Symbols, no place in `stats.totalFiles` and no `stats.skippedFiles` entry, and `ignore` could not bring them back. With `src/a.ts`, `.github/actions/deploy/src/main.ts` and `.storybook/main.ts` tracked, `aburi scan` printed `1 kept · 0 dropped · 1 files`; it now prints `3 kept · 0 dropped · 3 files`, with `ts:.github/actions/deploy/src/main.ts#run` and `ts:.storybook/main.ts#config` beside `ts:src/a.ts#a`. `.git` stays out as a stated core pattern, `**/.git/**`, which also keeps a nested repository's or a submodule's `.git` from being listed at all. Yarn's `.yarn/`, `.pnp.cjs` and `.pnp.loader.mjs` are core patterns too: Yarn's own setup commits its release, plugins and editor SDKs, and under zero-installs its Plug'n'Play loader. In `ignore`, in the core patterns and in a language plugin's drop patterns, `*` and `**` now match a name that starts with a dot, so `"ignore": ["docs/**"]` leaves out `docs/.vitepress/` as well.

Component detection follows: the language census counts files in dot directories, and the nx detector finds a `project.json` in one, as nx itself does. The resolution of `pnpm-workspace.yaml` and `workspaces` patterns still reads them as pnpm and npm do: `packages/*` does not match `packages/.template`, and `.github/actions/*` matches `.github/actions/deploy`.

Only a workspace with files of a claimed extension under a dot directory, or dot files such as `.eslintrc.js`, sees a difference. There, an IR scanned before this release, compared with one scanned after, reports those files' Symbols as added, once, and a gate on `added` trips. A file among them over `maxFileSizeBytes` now appears in `stats.skippedFiles`. Calls into them now resolve, so their callers gain `dependencies[]` edges and, with an effect plugin loaded, the effects that propagate along them, which moves those callers' `logic` fingerprints. A component's `languages` counts the files, and an nx project kept in a dot directory becomes a Component of its own, taking its files' Symbols from the Component that held them. On this repository, scanning one tree with both versions counts four more files under `docs/.vitepress/` and `.claude/`, adds 18 Symbols from two of them, one of those dropped, and one dependency edge between them, and moves no fingerprint. Rescan the base rather than comparing against a stored IR. `aburi diff <base>..<head>` scans both sides with this release and is unaffected.
