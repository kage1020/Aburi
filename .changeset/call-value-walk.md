Walk the whole call a `const` or a default export is computed by. What the call calls and everything it is handed — a class (`withAudit(class { … })`), an object (`t.router({ byId: publicProcedure.query(…) })`), a function nested in an argument, the functions an awaited call is handed — now land on the binding the call computes, as the same call written as a statement of its own lands on `<module>`. So `const n = await prisma.user.deleteMany({})` carries its `db.write`, `export default defineConfig({ plugins: [react()] })` is a `<default>` Symbol whose calls are `defineConfig` and `react`, and a resolver written inside a tRPC router's object literal is the router's, so an edit to it is a logic change. The functions a call is handed directly are still read as functions of their own, where they are written, so their rules are unchanged; the call that wraps them (`withAuth`, `memo`) is now one of the const's calls.

On the nine benchmark repositories no `syntax` fingerprint moves and no Symbol goes away. Each gains up to 94 `<default>` Symbols (mostly `vite.config.ts`-style configuration files) and 0.2–9% more call sites (trpc 22,695 → 24,719, cal-com 120,257 → 127,504, CommonJS `require(…)` consts among them), and the `logic` fingerprint moves on the consts whose call held rules no Symbol read before (0–74 per repository).
